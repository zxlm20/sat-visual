## 总体目标

在 `feature/constellation-groups` 分支上实现独立的**星座分组配置管理模块**，包含：

1. 查询全部星座分组和未分配卫星
2. 新建、修改和删除星座
3. 编辑星座名称、颜色、描述和成员
4. 将卫星移动到指定星座 / 移出星座
5. 支持一次性保存全部星座配置
6. 支持恢复默认星座（二次确认）
7. 显示成员数量、轨道层、跨层标识
8. 错误时在界面展示后端 `detail`，不静默失败
9. 对外提供当前选择的 `constellation_id`
10. 独立的 Demo 测试页面挂载真实组件和真实接口

- `resetDefaults()` — 恢复默认

## 附录：接口速查表

### 请求


| # | 方法   | 路径                                                 | 请求体                                                                     | 说明      |
| --- | -------- | ------------------------------------------------------ | ---------------------------------------------------------------------------- | ----------- |
| 1 | GET    | `/api/constellations/groups?include_unassigned=true` | —                                                                         | 查询全部  |
| 2 | POST   | `/api/constellations/groups`                         | `{constellation_id?, constellation_name, color?, description?, members[]}` | 新增/修改 |
| 3 | PUT    | `/api/constellations/groups`                         | `{groups: [{...}, ...]}`                                                   | 保存全部  |
| 4 | POST   | `/api/constellations/groups/move-member`             | `{node_id, constellation_id}`                                              | 移动卫星  |
| 5 | DELETE | `/api/constellations/groups/members/{node_id}`       | —                                                                         | 移出卫星  |
| 6 | DELETE | `/api/constellations/groups/{constellation_id}`      | —                                                                         | 删除星座  |
| 7 | POST   | `/api/constellations/groups/reset-defaults`          | —                                                                         | 恢复默认  |

### 响应关键字段


| 字段                          | 类型     | 说明                  |
| ------------------------------- | ---------- | ----------------------- |
| `groups[].constellation_id`   | string   | 星座唯一 ID           |
| `groups[].constellation_name` | string   | 星座名称              |
| `groups[].color`              | string   | 十六进制颜色          |
| `groups[].description`        | string   | 描述                  |
| `groups[].members`            | string[] | 成员卫星 node_id 列表 |
| `groups[].member_count`       | number   | 成员数量              |
| `groups[].orbit_layers`       | string[] | 包含的轨道层          |
| `groups[].cross_layer`        | boolean  | 是否跨轨道层          |
| `unassigned`                  | string[] | 未分配卫星列表        |
| `unassigned_count`            | number   | 未分配卫星数量        |
